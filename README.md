# 🔐 Password Manager

A secure password management web application built using Python and Flask.

## ✨ Features

- 🔑 Master password authentication
- ➕ Add account credentials
- 👁️ View and hide passwords
- 🔍 Search accounts
- ✏️ Update account details
- 🗑️ Delete accounts
- 🔒 Fernet password encryption
- 🎲 Password generator
- 💪 Password strength checker
- 📋 Copy password to clipboard
- 💾 Persistent file-based storage

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Cryptography

## 🎯 Project Purpose

This project demonstrates secure credential management, file handling, encryption, authentication, and web application development using Python and Flask.
